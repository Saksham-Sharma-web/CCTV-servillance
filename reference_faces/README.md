# Reference Faces Directory

Place reference photos of people you want the CCTV surveillance system to recognize here.

### Naming Convention:
- `Name_most_recent.jpg` — for the person's current appearance (e.g. `Akshat_most_recent.jpg`, `Amit_most_recent.jpg`)
- `Name_recent.jpg` — for reasonably recent photos (e.g. `Amit_recent.jpg`)
- `Name_old.jpg` — for older photos where clothing/body should be ignored (e.g. `Amit_old.jpg`)
- `Name.jpg` — defaults to `most_recent`

The system will automatically load and validate all photos in this directory when starting the live stream.
